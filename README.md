# Discord Test Site

Scraped Discord login page served as a static site.

## 🚀 Deployment

### Railway
1. Click "Deploy on Railway" or connect this repo
2. Railway will auto-detect the Node.js app
3. It will run `npm install` and `npm start` automatically
4. Your site will be live!

### Local Development
```bash
npm install
npm start
```

Visit http://localhost:3000

## 📁 Structure
- `index.html` - Main HTML page
- `css/` - Stylesheets
- `js/` - JavaScript files
- `server.js` - Express server for deployment
- `manifest.json` - Metadata

## 🔧 Tech Stack
- Node.js + Express (server)
- Static HTML/CSS/JS (scraped from Discord)
